# DK-01 - Defusal Kit

## Visão Geral

O DK-01 é uma plataforma eletrônica modular para Paintball, Airsoft, Laser Tag e jogos táticos.

## Estado Atual

- Arquitetura definida
- Placa principal hexagonal (100 mm)
- ESP32-S3-WROOM-1-N16R16
- Display remoto 2.1" 480x480 via FFC
- 12 módulos de portas
- Bateria 18650 1S2P
- USB-C
- LVGL
- KiCad 10.0.4

Este repositório contém a documentação de engenharia.
