# Automation

Esta pasta contém scripts responsáveis por automatizar a criação e manutenção do projeto.

Nenhum script deve sobrescrever arquivos existentes.

Todos devem ser idempotentes.

Objetivos:

- Criar estrutura inicial.
- Validar estrutura.
- Gerar documentação.
- Gerar índices.
- Exportar PDF.
- Validar links.
- Validar IDs.
- Validar requisitos.
- Auxiliar geração do KiCad
